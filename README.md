# Foodly Backend 🍔🚀

Backend API for Foodly (Food Delivery App).  
Built with Node.js, Express, MongoDB (Mongoose), and JWT authentication.

## ✨ Features
- Auth (User/Vendor) with JWT
- Categories / Products / Orders APIs
- File upload (optional)
- Stripe payments (optional)
- Role-based access (User / Vendor / Admin)
- Pagination + Filtering (optional)

## 🧰 Tech Stack
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- dotenv
- (Optional) Stripe

---

## ✅ Requirements
- Node.js >= 18
- MongoDB (local or Atlas)
- Git
